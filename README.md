# Ovarian Cancer Survival Analysis

## Overview

This project investigates demographic and clinical predictors of ovarian cancer survival using data from the SEER (Surveillance, Epidemiology, and End Results) database.

## Dataset

* SEER Database
* 124,215 ovarian cancer patients
* Variables analyzed:

  * Age
  * Race/Ethnicity
  * Stage at Diagnosis
  * Tumor Grade

## Methods

* Kaplan-Meier Survival Analysis
* Cox Proportional Hazards Regression
* Statistical Modeling in R
* Data Visualization

## Key Findings

* Stage at diagnosis was the strongest predictor of mortality.
* Distant-stage disease was associated with substantially higher mortality risk.
* Advanced age and higher tumor grade were associated with poorer survival outcomes.
* Significant racial disparities in survival were observed.
